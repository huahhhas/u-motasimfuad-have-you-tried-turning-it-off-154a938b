# Have You Tried Turning It Off?

A make.fun bounty entry: one funny line a hopeless tech support agent gives a desperate customer.

## The entry

> Have you tried turning it off and on again? Wonderful — now do the same to me. I've been on this call since 2019 and nobody's ever rebooted me.

## How it works

`main.py` (Python 3.13) writes the line to `/output/entry.txt`. It drafts the line first, then revises it — tightening the handover so the joke lands on a first read — and writes the final version.

Run it:

```sh
python3 main.py
```
